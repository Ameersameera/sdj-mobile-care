## SDJ Mobile Care – Smart Shop Management System

Offline shop software for Windows 10 / 11 (64-bit): billing, quick sale, stock, purchases, repair jobs,
customers & dues, expenses, returns, daily closing, reports and accounting.

### Download
- **SDJMobileCare_Setup_1.0.0.exe** – Windows installer (recommended)
- **SDJMobileCare-Windows-app-….zip** – portable version: extract it and run `SDJMobileCare.exe` (no install)

### Install pannradhu eppadi
1. `SDJMobileCare_Setup_1.0.0.exe` download panni double-click pannunga.
2. "Windows protected your PC" vandhaa → **More info** → **Run anyway**.
3. **Install for all users** → **Next** → **Install** → **Finish**.
4. Desktop-la **SDJ Mobile Care** icon varum. Practice panna Start menu-la **SDJ Mobile Care (demo data)**.

All data stays on the shop computer. Automatic daily backup is on by default (Settings → Backup).
