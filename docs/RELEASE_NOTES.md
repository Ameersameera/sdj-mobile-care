## SDJ Mobile Care – Smart Shop Management System

Offline shop software for Windows 10 / 11 (64-bit): billing, quick sale, stock, purchases, repair jobs,
customers & dues, expenses, returns, daily closing, reports and accounting.

### What's new in 1.1.0
- **Your own product categories** – *Settings → Categories*: add a category, rename it, choose Mobile / Accessories /
  Spare parts and IMEI tracking, or hide categories you don't use. Categories are never deleted, so old bills and
  reports stay correct.
- **+ button** next to *Category* in *Add product* – make a new category without leaving the product form.

### Download
- **SDJMobileCare_Setup_1.1.0.exe** – Windows installer (recommended)
- **SDJMobileCare-Windows-app-v1.1.0.zip** – portable version: extract it and run `SDJMobileCare.exe` (no install)

### Install / update pannradhu eppadi
1. `SDJMobileCare_Setup_1.1.0.exe` download panni double-click pannunga.
2. "Windows protected your PC" vandhaa → **More info** → **Run anyway**.
3. **Install for all users** → **Next** → **Install** → **Finish**.
4. Desktop-la **SDJ Mobile Care** icon varum. Practice panna Start menu-la **SDJ Mobile Care (demo data)**.

Already 1.0.0 install pannirundhaa, app-ai close panni idhe setup-ai run pannunga – pudhu version mela install aagum,
unga data (bills, stock, customers) appadiye irukkum.

All data stays on the shop computer. Automatic daily backup is on by default (Settings → Backup).
