## SDJ Mobile Care – Smart Shop Management System

Offline shop software for Windows 10 / 11 (64-bit): billing, quick sale, stock, purchases, repair jobs,
customers & dues, expenses, returns, daily closing, reports and accounting.

### What's new in 1.2.0
- **Reset data** – *Settings → Reset* (owner only): clear Sales & bills, Repair jobs, Purchases, Expenses, Daily closings,
  Stock, Products, Customers or Suppliers – for all time or a From–To date range – or do a **Full reset**.
  Shows exactly what will be removed first, asks for your password and the word RESET, takes a backup, and
  **Undo last reset** brings everything back. Stock, phones (IMEI) and closed-day figures are put right automatically.
- **Edit bill** – *Sales History → open a bill → Edit bill*: change items, prices or payment of an open-day bill.
  The invoice number stays the same; the old version is kept as cancelled.
- **Owner approval for staff** – staff can cancel / edit a bill, adjust stock or give a discount above the limit you set
  when the owner or a manager types their password (*Settings → Users*). Every approval goes into the audit log.

### Install / update pannradhu eppadi
1. `SDJMobileCare_Setup_1.2.0.exe` download panni double-click pannunga.
2. "Windows protected your PC" vandhaa → **More info** → **Run anyway**.
3. **Install for all users** → **Next** → **Install** → **Finish**.
4. Desktop-la **SDJ Mobile Care** icon varum. Practice panna Start menu-la **SDJ Mobile Care (demo data)**.

Pazhaya version install pannirundhaa, app-ai close panni idhe setup-ai run pannunga – pudhu version mela install aagum,
unga data (bills, stock, customers) appadiye irukkum.

All data stays on the shop computer. Automatic daily backup is on by default (Settings → Backup).
